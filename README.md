# Durys Kurylys · кровля и фасад, Шымкент

Многостраничный сайт кровельно-фасадной компании: Next.js 16 (App Router, Turbopack), TypeScript strict, Tailwind CSS v4, GSAP + ScrollTrigger, Lenis.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшн-сборка
npm run typecheck  # tsc --noEmit
```

## Правило честности

Это не маркетинговая рыба, а сайт конкретной компании, и он не должен обещать того, чего нет.

- **Никаких «реализованных объектов».** Реальных фото с объектов компании нет, поэтому раздела «портфолио» на сайте нет тоже. Вместо него — `/services`: что входит в работу и что проверять при приёмке. Стоковые кадры там иллюстрируют технологию, а не выдаются за свои работы.
- **Отзывы — дословно из 2ГИС**, вместе с именами и датами (`src/content/reviews.ts`), со ссылкой на источник. Три отзыва — значит три.
- **Цифры только проверяемые**: рейтинг 5,0 и 6 оценок в 2ГИС, 10 брендов с вывески офиса, график Пн–Сб 09:00–22:00. Ни «12 лет на рынке», ни «240+ объектов», ни «гарантия 5 лет» — этих данных у нас нет.
- **Фото компании** — только из `assets-src/photos/real/` (офис и шоурум на Пошанова, 31, из карточки 2ГИС).

Появятся реальные фото объектов, БИН, срок гарантии или стаж — добавляйте. Придумывать их не нужно.

## Что заполнить перед запуском

### 1. Тексты и данные — `src/content/`

Все тексты, цифры и контакты лежат в `src/content/*.ts`. В компонентах ничего не захардкожено.

| Файл | Что внутри |
|---|---|
| `site.ts` | контакты, адрес, график, координаты, список брендов, рейтинг 2ГИС, тексты героя, манифеста, блока доверия, процесса, CTA |
| `materials.ts` | 6 материалов (3 кровля + 3 фасад): применение, срок службы, основание, бренды, `priceFrom` (сейчас `null` → «цена по расчёту») |
| `services.ts` | 8 услуг с фильтром по направлению: состав работ и чек-лист приёмки |
| `reviews.ts` | отзывы из 2ГИС — менять только вместе с источником |
| `calculate.ts`, `layers.ts`, `regulations.ts`, `documents.ts`, `faq.ts` | секции главной |
| `pages.ts` | hero и SEO внутренних страниц, шоурум, «О компании», 404, «Спасибо» |
| `nav.ts` | меню, мега-меню, футер, мессенджеры |

Заголовки задаются массивом строк: каждая строка — отдельная строка каскада, `*слово*` — акцент терракотой.

### 2. Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните:

- `NEXT_PUBLIC_SITE_URL` — боевой домен без слэша в конце (нужен для canonical, OG и sitemap);
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather;
- `TELEGRAM_CHAT_ID` — чат, куда приходят заявки.

В режиме разработки без токенов заявка просто пишется в консоль сервера. В продакшне форма без них вернёт ошибку «Форма временно недоступна».

### 3. Фотографии — `public/images/`

Картинки собирает `npm run images` из двух источников, и путать их нельзя:

- **`assets-src/photos/real/`** — настоящие снимки компании (офис, витрина, шоурум). Только они стоят там, где речь о самой компании: hero «О компании», «Контакты», «Шоурум», галерея шоурума и карточка в блоке доверия.
- **`assets-src/photos/stock/`** — Unsplash (`npm run stock` скачивает заново, список и ссылки — в `SOURCES.md`). Иллюстрации материала и технологии: hero главной, материалы, услуги. Лицензия Unsplash разрешает коммерческое использование без атрибуции.

Скрипт падает, если два слота берут одно и то же стоковое фото (кроме art direction героя: desktop и mobile — один кадр в двух кадрировках).

Реальные снимки кладите **с теми же именами** поверх текущих:

| Папка | Пропорция | Файлы |
|---|---|---|
| `hero/` | 16:9 | `home`, `materials`, `services`, `showroom`, `about`, `contacts` |
| `hero/` | 4:5 | `home-mobile` — вертикальный кадр героя главной для телефонов |
| `home/` | 3:2 | `showroom` — карточка «10 брендов»; `process` — секция «Как работаем» |
| `materials/` | 4:5 | по `slug` материала |
| `services/` | 4:3 | по имени из `services.ts` |
| `showroom/` | 3:2 | `stands`, `samples`, `entrance` |

### 4. Шрифты — `public/fonts/`

Все четыре семейства — OFL 1.1 с github.com/google/fonts, исходники и лицензии в `assets-src/fonts/`. `npm run fonts` собирает из них `.woff2` с сабсетом «латиница + кириллица (включая казахские) + ₸, №, стрелки».

| Шрифт | Вес | Роль |
|---|---|---|
| Unbounded | 600, 700 | логотип и вордмарк — и больше нигде |
| Geologica | 700, 800 | заголовки h1/h2, крупные цифры, капслок |
| Manrope | 400, 500, 600 | весь текст и интерфейс |
| IBM Plex Mono | 400 | eyebrow, числа, сроки, ТТХ (tabular-nums) |

Тот же скрипт кладёт `og-*.ttf` для `opengraph-image`: satori в `next/og` не читает woff2.

Шрифт логотипа меняется в одном месте — `--font-logo` в `src/app/globals.css`.

### 5. Логотип

`src/components/ui/Logo.tsx` — монограмма DK, нарисованная по табличке и вывеске офиса: это аппроксимация, а не оригинальный файл. Будет исходник от клиента — замените `Mark` и `src/app/icon.svg`.

### 6. Цвета

Палитра задана токенами в `@theme` (`src/app/globals.css`): холодный бетон `#E4E5E7`, графит `#1A1A1D`, акцент-терракота `#C8542B`. Менять только там — остальное считается от них.

## Устройство

```
src/
  app/           страницы, api/lead, sitemap, robots, opengraph-image
  components/
    layout/      Header, MegaMenu, MobileMenu, Footer, SmoothScroll, Preloader
    home/        секции главной (Hero, Manifesto, Brands, RoofSection, Reviews, …)
    ui/          примитивы: Heading, Reveal, SectionCard, SpecTable, Modal, Accordion…
    forms/       LeadForm, LeadModal (глобальная модалка), LeadButton
    services/    ServicesExplorer (фильтр услуг)
  content/       все тексты и данные
  lib/           fonts, gsap, seo, validation, splitWords
  hooks/         useReveal, useCountUp, useLockBody, useScrolled, useMediaQuery
```

- **Прелоадер**: буквы DURYS / KURYLYS поднимаются из-под маски, затем шторка уходит вверх. Показывается один раз за сессию, при reduced motion не показывается. Интро героя стоит на паузе, пока шторка на экране.
- **Кровельный пирог в разрезе** (`home/RoofSection.tsx`) — SVG-схема из шести слоёв с выносками; наведение подсвечивает слой, на телефоне это аккордеон.
- **Tilt-in карточек**: элементу с `data-reveal="tilt"` внутри `<Reveal>` достаётся подъём из наклона rotateX 35° с перспективой 1200px.
- **Анимации.** Начальные состояния reveal задаёт CSS только при включённом JS (`html.js`) и без `prefers-reduced-motion`. GSAP везде делает `.to()`. При reduced motion Lenis не включается, анимации не играют.
- **Заголовки** рендерятся дважды: цельный `sr-only` h1/h2 для SEO и визуальная копия, разбитая на слова функцией `splitWords()`.
- **Шапка** светлеет или темнеет сама: поверх блока с `data-hero="dark"` текст светлый, иначе тёмный (CSS `:has`).
- **Формы**: zod + react-hook-form, маска телефона `+7 (XXX) XXX-XX-XX`, honeypot, rate-limit 5 заявок на IP за 10 минут (in-memory). Способы связи — звонок и WhatsApp: Telegram у компании нет.
- **SEO**: `generateMetadata` на каждой странице, canonical, OG/Twitter, JSON-LD (Organization, HomeAndConstructionBusiness с координатами, графиком и рейтингом, BreadcrumbList, FAQPage, Service), динамические sitemap и robots.

Первый экран анимируется чистым CSS (`.anim-in`, `.anim-word`, `.anim-letter`), а не GSAP: так LCP не ждёт гидратацию.

> Путь проекта содержит кириллицу и пробелы. Turbopack на Next 16.4 собирает его без проблем, но все пути **внутри** проекта — только латиница.
